# Settled implementation decisions

- Keep the feature co-located in the `jev-review` plugin. Adopt the brief's proposed v1 defaults unless implementation evidence contradicts them; record any consequential change before widening scope.
- Keep provider evaluation, goal policy, and Codex integration as separate layers. General evaluation reuses Jev's native typed questions and current provider setup. A replaceable injected judge returns bounded signals plus native answers/provenance; Codex owns repository discovery, goal wording, and user questions.
- Use deterministic routing. Preserve distinct `answer`, `discuss`, `investigate`, and `implement` intents; distinguish new/refine/replace/clarification-answer/unrelated turns; retain clear/inferable/ambiguous/absent/not-needed goal states. Ask about unresolved core concepts and preferences. Do not turn an inferred goal or high confidence into permission.
- Ship `off`, `observe`, and explicit `assist`, with `observe` initially selected. The UserPromptSubmit command performs bounded initial triage and emits fixed instructions/data. The skill handles discovery, candidate wording, MCP assessment, and questions. Keep a manual skill entrypoint and do not simulate or invoke native `/goal`.
- Scope product state to session and workspace; use versioned atomic updates, stale-revision rejection, and duplicate-event idempotence. Missing state falls back to conversation context without reviving an old goal.
- Preserve current MCP tools, Bun packaging, credentials, and OpenRouter compatibility. The user explicitly chose OpenRouter only on 2026-09-27; direct TypeSafe provider support is outside this goal. Never send attachments, full transcripts, or repository files automatically. Remote triage can send submitted prompt text when enabled; explain this. Diagnostics default to metadata, redact content, and require explicit opt-in for content recording and deletion.
- Use fictional/synthetic or paraphrased cases, never private chat history. Compare all three conditions with matched generator model, context, tools, and budgets. Keep held-out labels private through prompt freeze; accept neutral or negative Jev results and keep observe as the default absent evidence and user choice.
- Planning ownership follows `specs/contracts.md` and each Beads issue's exact `metadata.writable_paths`. The coordinator owns shared MCP registration, manifests, package composition, generated output, result reporting, and all Beads mutations. Read-only review issues have empty writable paths and cannot be dispatched until the coordinator records an immutable candidate SHA.
- Integration uncertainties are evidence gates, not reopened product choices: verify the native hook schema/trust/invocation and native goal metadata on the installed Windows Codex host; validate provider response limits and any thresholds against the selected model. If unavailable, preserve the source and report the unverified gate.
